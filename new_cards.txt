# Cards added to EDS after its 820 original cards, one per line, in the order they get card IDs (821, 822, ...).
# Edit this list and run `python3 tools/card_expand/write_tables.py --rom eds.gba`: it looks each name up on
# YGOPRODeck (https://ygoprodeck.com/api-guide/), downloads its stats, text and cropped art into
# assets/new_cards/, assigns card IDs and card numbers, and writes build/card_expand/expanded.gba.
# Use the exact English card name as YGOPRODeck spells it.
#
# A name longer than 41 characters does not fit a Deck Edit list row; give the name to show in the game after
# a "|":   Black Luster Soldier - Envoy of the Beginning | Black Luster Soldier - Envoy of Beginning
# Values the API lacks (tokens have no attribute, level, ATK or DEF) or that should differ go after a second "|":
#          Sheep Token | | attr=EARTH level=1 atk=0 def=0
# Keys: atk, def, level, attr, race, number (card number), password (8 digits or none).
# Lines starting with # and blank lines are ignored.
# Changing the list changes the card IDs after the change, so saves made with another list show other cards.
