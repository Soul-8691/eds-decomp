# Card Prices

The DP the card password machine charges, per format, from the format's deck usage statistics (`usage/`). Generated by `python3 tools/cardprices.py --md CARD_PRICES.md`; do not edit.

- **Price.** The share of the format's decks that run the card (main + side) times 1000, plus its Extra Deck share times 100; times 3 if the card is Limited in that format, times 1.5 if Semi-Limited; then scaled linearly so the format's cheapest listed card is 200 DP and the priciest is 3000 DP.
- **Which format.** The game uses the newest format you have unlocked whose decks use the card.
- **Not listed.** Cards a format's decks don't use: those keep their price from an earlier format, or cost 100 DP if they never appear in any unlocked format's usage table.
