# Card Prices

The DP the card password machine charges, per format, from the format's deck usage statistics (`usage/`). Generated by `python3 tools/cardprices.py --md CARD_PRICES.md`; do not edit.

- **Price.** The copies of the card an average deck of the format runs (main + side) times 5000/3 (about 1667), plus its Extra Deck copies per deck times a tenth of that; times 3 if the card is Limited in that format, times 1.5 if Semi-Limited; then kept between 200 and 5000 DP. A Limited card in every deck is 1667 x 3 = 5000 DP; a Semi-Limited card run at two copies is 3333 x 1.5 = 5000 DP.
- **Outside the card pools.** A card not in the Reaper card pool always costs 5000 DP, whatever format it was priced in; so does a card in no unlocked format's card pool (a card of a format you have not unlocked yet).
- **Which format.** The game uses the newest format you have unlocked whose decks use the card.
- **Not listed.** Cards a format's decks don't use: those keep their price from an earlier format, or cost 100 DP if they are in an unlocked format's card pool but in no unlocked format's usage table.
